This is a super simple platformer. It doesn't scroll (I couldn't figure out a scroll background), so it's one screen.
I had a blast figuring out how to make a little animated hobbit as the main player. 
He's super cute in my opinion.
I kept it nature theme: I have grass jumping blocks and a fantasy world background.
I added a label at the end so people know where the end is (just in case you couldn't tell).
I tested it and I like the movements and you can get to all the platforms you need to.
It's super easy to get to the end.
